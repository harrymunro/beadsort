# Code of Conduct

Be kind, be direct, assume good faith. Disagree with ideas, not people. No harassment, no discrimination, no personal attacks, in issues, pull requests or anywhere else this project meets.

If something goes wrong, email harry@schoolofsimulation.com. Reports are handled privately and taken seriously.

Maintainers may remove, edit or reject contributions and comments that do not follow this, and may ban repeat offenders.
